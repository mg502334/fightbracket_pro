Overview
FightBracket Pro is a competitive gaming platform that includes authentication, identity management, admin‑level operations, and privileged API routes. Because of this, security is a core priority.

This document outlines the security expectations, handling of sensitive data, and contribution rules for anyone interacting with the repository.

⚠️ Private Project Notice
This repository is not public and is not open to external contributions.
Only approved collaborators may access, modify, or review the codebase.

Unauthorized access, distribution, or modification is strictly prohibited.
